01 / Dual-rail encoding

A single qubit uses |0⟩L = |01⟩ and |1⟩L = |10⟩. For two qubits, the control rails are reversed to match the four-mode arrangement on p.294 of the textbook.

|00⟩ → |1001⟩   |01⟩ → |1010⟩
|10⟩ → |0101⟩   |11⟩ → |0110⟩

02 / Beam splitter & phase

We use the explicit real matrix in Eq. (7.35) as our beam-splitter convention, with consistent signs throughout.

B(θ) = [[cos θ, −sin θ], [sin θ, cos θ]]
P(φ) = diag(1, eiφ)
UMZI = B(−θ) P(φ) B(θ)

θ = π/4 gives a 50:50 splitter. For input |0⟩, P(1) = sin²(2θ) sin²(φ/2). At φ = 0, the two beam splitters cancel.

03 / Kerr → CNOT

Only the |11⟩ component, with a photon in each of the two middle modes, acquires a phase. H acts on the target qubit.

K(ξ) = diag(1, 1, 1, eiξ)
U = (I ⊗ H) K(ξ) (I ⊗ H)
H = B(π/4) diag(1, −1)

At ξ = π, the circuit implements CNOT. Input |+0⟩ produces the Bell state (|00⟩ + |11⟩)/√2.

04 / Reading the state

A component with complex amplitude a has measurement probability |a|². Fidelity F = |⟨ψideal|ψ⟩|² compares the state at the selected point with the ideal final output for this input. It is not a gate fidelity.

For a pure two-qubit state a|00⟩ + b|01⟩ + c|10⟩ + d|11⟩, concurrence is C = 2|ad − bc|. A value of 0 means a product state; 1 means maximal entanglement.

Physical limitations: This model reproduces the ideal dual-rail encoding and optical gates described in §7.4 of the textbook. Circuit-state, interference, and fidelity visualizations are additional features. It does not model hardware for arbitrary initial-state preparation, measurement, or sequences of arbitrary gates, and is not a practical, general-purpose quantum computer. Photon loss, distinguishability, and detector imperfections are omitted. The Kerr phase shift ξ = π required for CNOT is an ideal assumption; the difficulty of achieving this interaction between single photons is discussed in §7.4.3. Realizing ideal gate operations in a simulation is not, by itself, sufficient to make a practical quantum computer.
